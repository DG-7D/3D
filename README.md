# 3Dモデル置き場

## Cable

- CableHolder: 網(35mm間隔)との間にケーブルを挟む形で留めるやつ
- CableHook: ケーブルにフックを嵌めて網にかけられるようにするやつ

## Camera

- SAL500F80Strap: MINOLTA AF REFLEX 500mm F8 (SONY版はSAL500F80) のキャップを紐で本体に固定できるようにするやつ。[使用例](https://x.com/DG_7D/status/1877521560396771775)
- Sight: シューに刺さる照準器。あんま使えない

## PCFan

- FanGuard: PCファンのファンガード
- FanGuard120Pin: ファンガードをスナップフィットでねじ穴に固定するピン
- FanPinStopper: 工研部室のファンのピンを基板から抜けないようにするやつ
